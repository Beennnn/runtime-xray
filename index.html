Runtime X-Ray

Rapports produits par l'analyse dynamique d'une exécution réelle.

Programme analysé : un calculateur de temps de trajet (22 classes, 8 packages). Exécution de ~10 s, 16 000 000 d'appels de la fonction analysée, sous Java 21. Tout ce qui suit est une sortie brute d'outil, pas une capture d'écran.

Par où le code est passé

Vue nettoyée CIBLÉE
Uniquement les classes réellement exécutées. Le code jamais atteint est retiré du rapport — on ne navigue que dans ce qui a servi.
Couverture complète JaCoCo
Tout le code, exécuté ou non. Source annotée ligne à ligne : vert exécuté, rouge jamais atteint, jaune branche partielle.
Descendre jusqu'au code : cliquer un package, puis une classe. Le fichier WeatherPenalty.java du package lab.sample.weather montre le cas le plus parlant — une branche rouge à l'intérieur d'une méthode exécutée des millions de fois.

L'arbre d'appel

Arbre d'appel async-profiler
Dépliable et cherchable, avec le pourcentage de temps par branche. Bouton « Expand All » pour tout ouvrir.
Flame graph
La largeur d'une barre est le temps passé. Cliquer pour zoomer sur une branche, taper pour chercher une méthode.

Java 21 contre Java 25 — la mesure

Java 21 — échantillonnage
Seulement jdk.ExecutionSample : quelques centaines de photos de la pile, dont on infère où le temps est passé.
Java 25 — comptage exact
16 000 000 d'invocations comptées, min/moyenne/max par appel. Et 594 877 piles d'appel exactes (extrait).

Avec quelles valeurs — l'option

Valeurs des paramètres ARTHAS
Les valeurs réellement passées : @Mode[CAR] @Weather[SUNNY] @TimeOfDay[RUSH_HOUR], et la valeur de retour. Là où JFR n'affiche que la signature.
L'arbre d'UN appel
Le chemin réellement emprunté par un seul appel, avec les numéros de ligne — de quoi retourner droit dans le source.

Ce qu'aucun de ces rapports ne montre

  • Les trois données dans un seul rapport. Aucun format ne les porte ensemble : il faut au minimum un fichier de couverture et un fichier de profil.
  • Le masquage des lignes non exécutées à l'intérieur d'un fichier. La vue ciblée retire les classes entières non touchées ; réduire un fichier à ses seules lignes exécutées n'est proposé nativement par aucun outil recensé.
Ces pages sont générées par les scripts du dépôt (tools/<outil>/collect.sh) à partir d'une exécution réelle.
